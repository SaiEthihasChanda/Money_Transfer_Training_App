# Free browser-hosted LLM chatbot

A chatbot that runs entirely in the visitor's browser via WebGPU
([WebLLM](https://github.com/mlc-ai/web-llm)). Firebase Hosting only serves
a small static app (HTML/CSS/JS, well under a megabyte) — the model weights
are downloaded straight from Hugging Face's CDN into the browser's cache the
first time someone loads a model, and every reply is generated by the
visitor's own GPU. There is no server-side inference, no API key, and no
per-request cost, so it fits comfortably inside Firebase Hosting's free
Spark plan (10GB storage / 10GB transfer per month) no matter how many
people use it.

## Why this architecture (and not a Node.js inference server)

Firebase Hosting can only serve static files — it cannot run Node.js. A real
Node.js backend would need Cloud Functions or Cloud Run, and running a
5-10GB LLM there on the free compute tier is impractical: cold starts alone
(loading a multi-gigabyte model into memory) take 30-90 seconds, and
CPU-only inference (no free GPU) turns each reply into a multi-minute wait
that burns through the free quota after a handful of chats. Running
inference client-side sidesteps all of that: Google's compute never touches
the model, so there's nothing to exhaust.

The trade-off: it requires a WebGPU-capable browser (recent Chrome/Edge;
Firefox/Safari support is still landing) and each visitor downloads the
model once (cached afterwards via the browser's Cache API / IndexedDB).

## Models

The model dropdown is populated at runtime from WebLLM's own prebuilt model
list (so it never goes stale), filtered down to a curated set that ranges
from ~1GB to ~5GB, all well under Firebase's 10GB Hosting limit even though
the model itself is never uploaded there:

| Model | Approx. size |
|---|---|
| Llama-3.2-1B-Instruct | ~0.9 GB |
| Qwen2.5-1.5B-Instruct | ~1.6 GB |
| Llama-3.2-3B-Instruct | ~2.3 GB |
| Qwen2.5-3B-Instruct | ~2.5 GB |
| Phi-3.5-mini-instruct | ~3.7 GB |
| Mistral-7B-Instruct-v0.3 | ~4.6 GB |
| Qwen2.5-7B-Instruct | ~5.1 GB |
| Llama-3.1-8B-Instruct (default) | ~5.0 GB |

Smaller models load faster and run more smoothly on modest hardware; larger
ones answer better. Edit `CURATED_MODEL_IDS` / `DEFAULT_MODEL_ID` in
`src/main.js` to change the lineup — any id from
`webllm.prebuiltAppConfig.model_list` works.

## Local development

```bash
npm install
npm run dev
```

Open the printed local URL in a WebGPU-capable browser (Chrome or Edge
113+), pick a model, click "Load model", and wait for the download/compile
progress bar to finish.

## Deploying to Firebase Hosting

1. Install the Firebase CLI if you don't have it: `npm install -g firebase-tools`
2. Log in: `firebase login`
3. From this directory, link it to your Firebase project:
   `firebase use --add` (pick or create a project, alias it e.g. `default`)
4. Build the static site: `npm run build` (outputs to `dist/`)
5. Deploy: `firebase deploy --only hosting`

Your chatbot will be live at `https://<your-project-id>.web.app`.

Re-run steps 4-5 whenever you change the app. No Cloud Functions, Cloud Run,
or billing (Blaze plan) are required for this architecture — Hosting alone
is enough.
